# Java Calculator

A simple console-based calculator built using Java.


## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Division-by-zero handling

## Concepts Used

- Variables
- Data Types
- Scanner
- Operators
- Switch Statement
- Conditional Statements

- ## Future Improvements

- Add continuous calculations
- Add more mathematical operations
- Improve input validation

```text
======= Basic Calculator =======

*
