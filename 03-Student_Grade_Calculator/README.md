# Student Grade Calculator 🎓

A simple console-based Student Grade Calculator developed using Java.

## 📌 Description

This program takes the number of subjects and marks obtained in each subject as input. It then calculates the total marks, percentage, highest marks, lowest marks, grade, and pass/fail status.

## ✨ Features

- Enter any number of subjects
- Enter marks for each subject
- Calculate total marks
- Calculate percentage
- Find highest marks
- Find lowest marks
- Assign grade automatically
- Display PASS or FAIL status

## 📊 Grading System

| Percentage | Grade |
|-----------:|:-----:|
| 90% and above | A+ |
| 80% – 89% | A |
| 70% – 79% | B |
| 60% – 69% | C |
| 50% – 59% | D |
| Below 50% | F |

### Pass Criteria

- **40% or above → PASS**
- **Below 40% → FAIL**
